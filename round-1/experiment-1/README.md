This experiment tests whether the difference between observed and predicted boiling points of water correlates with vertical wind turbulence, which would indicate non-hydrostatic pressure effects in the atmosphere.

## Full Summary

Implemented and executed the experiment to test the non-hydrostatic hypothesis by correlating boiling point prediction error (T_obs - T_calc) with vertical wind turbulence (w). The methodology follows the artifact plan: (1) Calculate hydrostatic boiling point baseline using Antoine equation from observed pressure; (2) Generate synthetic high-frequency (1 Hz) meteorological data with 5000 points per run, across 12 independent runs with different seeds; (3) Compute boiling point prediction error; (4) Perform Pearson correlation between T_error and w; (5) Power Spectral Density analysis using scipy.signal.welch. Results from 12 runs: Pearson correlations range from -0.0196 to +0.0389 (all |r| < 0.05, as expected since T_calc uses observed pressure), mean T_error ~ 0°C, std T_error ~ 0.01°C.
