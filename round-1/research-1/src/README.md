# Assessing Alternative Boiling Point Hypotheses

This research investigates the standard models for predicting the boiling point of water at altitude, specifically examining how aerosol loading and lapse-rate variability impact these predictions compared to observed deviations.

## Layout
- `.sdk_openhands_agent_struct_out.json`: Structured research output.
- `reproducibility.md`: Documentation of search methodology.
- `README.md`: This file.

## How to run
This is a research project, not an executable codebase. The findings can be found in `.sdk_openhands_agent_struct_out.json`.
