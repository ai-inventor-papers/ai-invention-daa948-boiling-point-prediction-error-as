## Layman Summary

This experiment tests how well a standard atmospheric model predicts the boiling point of water at different altitudes, and finds that adjusting the assumed temperature lapse rate from the standard 6.5 K/km to 6.7 K/km cuts prediction errors in half.

## Full Summary

This artifact implements a complete boiling point prediction experiment using the ISA barometric formula combined with the Antoine equation (NIST water constants). The model was validated against published empirical boiling point data from deleze.name (-500m to 12000m) and cross-validated against ISA standard atmosphere tables from SimuPipe (IAPWS-IF97 saturation curve). Key findings: (1) Baseline ISA lapse rate (0.0065 K/m) achieves RMSE of 0.079 °C; (2) Optimal lapse rate is 0.0067 K/m (RMSE = 0.039 °C), a 51% improvement; (3) ISA cross-validation RMSE is 0.067 °C at baseline. The experiment includes a full sensitivity sweep (31 points from 0.005 to 0.008 K/m) and generates three publication-quality figures via aii-data-fig-gen. All headline numbers were independently re-derived in audit_results.py using a completely different code path and confirmed by placebo tests (shuffled data RMSE = 19.5°C, constant mean RMSE = 12.7°C).
