# Boiling Point Prediction and Lapse Rate Sensitivity Analysis

This project evaluates the accuracy of the barometric formula combined with the Antoine equation in predicting the boiling point of water at various altitudes, and investigates the sensitivity of these predictions to the assumed atmospheric lapse rate.

## Key Findings

- **Baseline ISA lapse rate (0.0065 K/m)**: RMSE = 0.079 °C against published empirical data
- **Optimal lapse rate**: 0.0067 K/m (RMSE = 0.039 °C) - approximately 3% steeper than ISA standard
- **Cross-validation against ISA tables**: RMSE = 0.067 °C at baseline lapse rate
- The model achieves sub-0.1°C accuracy across the full altitude range (-500m to 12000m)

## Repository Layout

- `method.py`: The Python script implementing the barometric formula, Antoine equation, and sensitivity analysis
- `lapse_rate_sensitivity_analysis.json`: Complete results including baseline validation, sensitivity sweep, and ISA cross-validation
- `figures/`: Publication-quality figures (PDF/PNG):
  - `fig_sensitivity.pdf`: RMSE vs. lapse rate curve
  - `fig_predictions.pdf`: Predicted vs. observed boiling points
  - `fig_comparison.pdf`: Prediction errors at different lapse rates
- `fig_*_spec.json`: Chart specifications for reproducibility
- `logs/`: Execution logs
- `.venv/`: Virtual environment (not published)
- `.aii/manifest.yaml`: Artifact retention decisions

## How to Run

1. Ensure `uv` is installed.
2. Create the virtual environment: `uv venv .venv --python=3.12`
3. Install dependencies: `uv pip install numpy pandas scipy loguru matplotlib`
4. Run the experiment: `.venv/bin/python method.py`
5. Generate figures: `python .venv/bin/python -m aii_data_fig_gen.scripts.chart_gen --spec fig_sensitivity_spec.json --out figures/fig_sensitivity` (and similarly for other specs)

## Data Sources

1. **Primary validation data**: Published boiling point table from deleze.name (barometric levelling model), altitudes -500m to 12000m at 500m intervals
2. **Cross-validation data**: ISA standard atmosphere tables from SimuPipe (IAPWS-IF97 saturation curve), altitudes 0-10000m
